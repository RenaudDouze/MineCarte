        Synchronisation cloud

        Sauvegarde tes lieux et chemins dans le cloud et retrouve-les sur tes autres appareils grâce à un code.

        Code

        Ce lien montre la carte, à jour, sans permettre de la modifier ni de voir le code. « Révoquer » le rend inutilisable.

        Les modifications sont synchronisées automatiquement. Toute personne qui connaît le code peut voir et modifier les données : ne le partage qu'avec qui tu veux.

        Données

        Historique local

        Copie automatique des données dans ce navigateur (au plus toutes les 10 minutes, et avant un import, un effacement ou une restauration). Les 10 dernières sont gardées.

          Aide

          • Clic droit (appui long au doigt) sur la carte : ajouter un lieu, démarrer un chemin, copier les coordonnées.
          • Clic sur un lieu : détails, liens et actions.
          • Recherche (/) : un nom de lieu ou de chemin, ou des coordonnées « X Z » / « X Y Z ». Depuis des coordonnées : depuis l'emplacement trouvé, créer un lieu, commencer un chemin, ajouter le point au bout d'un chemin ou au tracé en cours.
          • Tracé : clic pour ajouter un point, clic sur un lieu pour s'y accrocher, double-clic ou Entrée pour terminer, Retour arrière pour annuler le dernier point, Échap pour abandonner.
          • Édition d'un tracé : glissez les sommets, clic sur un segment pour insérer un point, clic droit sur un sommet pour le supprimer.
