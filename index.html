      Aide

      • Clic droit sur la carte : ajouter un POI, démarrer un chemin, copier les coordonnées.
      • Clic sur un POI : détails, liens et actions.
      • Aller à (X, Y optionnel, Z) : depuis l'emplacement trouvé, créer un POI, commencer un chemin, ajouter le point au bout d'un chemin ou au tracé en cours.
      • Tracé : clic pour ajouter un point, clic sur un POI pour s'y accrocher, double-clic ou Entrée pour terminer, Retour arrière pour annuler le dernier point, Échap pour abandonner.
      • Édition d'un tracé : glissez les sommets, clic sur un segment pour insérer un point, clic droit sur un sommet pour le supprimer.
